{# The lists panel: a column down the left listing every list on the board, where clicking one shows or hides it. Which lists are hidden, and whether the panel is a strip, are per device and per board, in localStorage (see the rail store in app.js). Hiding is a generated CSS rule, so a board refresh doesn't undo it. The items are read from the board rather than rendered here, so adds, renames, deletes and drags all show up without the server (see boardRail). The panel sits outside #lists-container, so a refresh never replaces it. #}
{# A hidden list stays in the panel, struck through: it's the way back. #}
